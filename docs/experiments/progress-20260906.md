## Manipulation and model direction

The existing ACT checkpoint remains the reproducible fixed-scene baseline. It
was trained for local pick-and-place, not separately validated pickup, sustained
hold during travel and release at another location. Recorded program completion
does not imply physical grasp success; past trials include failures, partial
successes and thermal stops. See the August 30 machine handoff.

SmolVLA is the first preparation target; X-VLA remains an alternative rather than
a committed replacement. The rationale and official sources are in
[the selection note](vla-selection-20260906.md). The training setup is documented
in [the Roihu runbook](smolvla-roihu-setup-20260906.md). No claim of new-task
generalization, dual-arm compatibility or Jetson real-time performance has been
verified. Keep navigation as a separate skill and use an explicit task state
machine for pickup/transport/place; a language model must not emit unrestricted
motor commands.
