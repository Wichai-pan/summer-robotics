# 实验记录 09 · 黑臂主控白臂与腕部跨圈修复

- **日期**：2026-08-09
- **平台**：Jetson Orin Nano Super + XLeRobot 黑/白 SO100 手臂
- **目标**：验证“黑臂手动示教、白臂实时复制”能否作为 ACT/VLA 数据采集入口，并解决 `wrist_roll` 在编码器 `4095/0` 附近错误旋转整圈的问题。
- **结果**：✅ 五个普通关节的相对主从控制可用；✅ 腕部单关节跨圈速度闭环通过双向实机测试；✅ 安全整臂脚本已验证大部分腕部动作可以到达所需位置；⚠️ 不再自动做两臂绝对角度对齐；⏳ 下一轮把该控制入口接入 LeRobot 数据录制。

## 1. 为什么继续使用相对跟随

两臂各自的标定零点不同。即使物理姿态接近，日志中的标定角也可能相差很大，例如一个关节显示负角、另一个显示正角。直接令白臂追逐黑臂的绝对数值，会产生没有物理意义的大幅对齐运动。

当前采用：

```text
白臂目标 = 白臂启动姿态 + sign ×（黑臂当前姿态 - 黑臂启动姿态）
```

输入 `FOLLOW` 的瞬间定义本次会话的相对零点。启动前由现场操作者把两臂人工摆到相似物理姿态；程序不自动执行绝对对齐。

## 2. 腕部事故与根因

早期绝对对齐测试中，白臂 `wrist_roll` 突然旋转接近一整圈并到达机械/线缆极限，触发 ID 5 overload，振动使数据线松脱。断电检查后没有发现持续性硬件损坏，腕部随后仍能低速正常运动。

根因是腕部为一圈循环关节，但位置控制把跨越 `4095/0` 的两个编码值视作数值区间两端：

```text
物理最短路径：4090 -> 3 = +9 ticks
错误位置路径：4090 -> 3 = -4087 ticks
```

仅在 Python 中把角度差包装到 `[-180°, 180°)` 仍不够，因为最终若把跨边界目标交给普通位置模式，舵机依然可能选择长路径。

因此旧 `tools/black_leads_white_smoke.py` 保留但设置为 **MOTION LOCKED**，防止队友误用事故路径。

## 3. 腕部修复方案

新增 `tools/wrist_roll_velocity_follow.py`，仅控制白臂 ID 5：

1. 黑腕保持松扭矩，只读 raw encoder；
2. 白腕切换为速度模式，启用扭矩前写入并回读 `Goal_Velocity=0`；
3. 每帧用最短 tick 差累计黑/白腕相对运动；
4. 根据相对角误差生成带死区、比例增益和最大速度的有符号速度；
5. 到达测试行程或收到 `q`/`Esc`/`Ctrl-C` 时写零速度并松扭矩；
6. 保留累计角边界，避免腕部相机/电机线缆被连续缠绕。

### 3.1 低速 20° 测试

```text
7.7 s: leader=-15.7°, follower=-11.9°, error=-3.9°
leader 到 -21.2° 后触发 ±20° 测试边界并停止
```

结果：方向正确，没有发生编码器跨圈长路径。

### 3.2 45° 测试

```text
启动 raw: black=4073, white=2274
18.4 s: leader=+42.4°, follower=+37.0°, error=+5.4°
leader 到 +45.1° 后正常停止
```

该测试明确跨过黑腕 raw `4095/0`，白腕仍沿正确方向跟随；结束时成功写零速度并松扭矩。

## 4. 安全整臂相对跟随

新增 `tools/black_leads_white_wrap_safe.py`：

| 关节 | 控制方式 |
|---|---|
| `shoulder_pan` | 相对位置跟随 |
| `shoulder_lift` | 相对位置跟随 |
| `elbow_flex` | 相对位置跟随 |
| `wrist_flex` | 相对位置跟随 |
| `gripper` | 相对位置跟随 |
| `wrist_roll` | 跨圈安全速度闭环 |

首次整臂测试将腕部限制为 `6°/s`。操作者约 3.5 秒内令黑腕移动约 `39°`，白腕因速度上限只追到约 `2°`，随后黑腕达到 `45°` 测试边界。这不是相对映射失败，而是速度上限和“到边界就结束整臂”的策略过于保守。

随后调整为：

- 腕部最大速度可独立设置；
- 达到累计角边界时夹紧白腕目标，但整臂循环继续；
- 黑腕回到允许范围后，白腕继续跟随并可返回本次会话零点。

现场复测确认，白腕现在大部分情况下能够旋转到所需位置，算法已基本满足当前主从示教需求。

## 5. 当前正式命令

同步到正式部署仓库后，从以下目录运行：

```bash
cd /home/jetsonl7/summer-robotics-deploy

./scripts/jetson_robot_exec.sh \
  --black --white --interactive -- \
  python3 tools/black_leads_white_wrap_safe.py \
  --white-id white_arm_leader_follow \
  --full-range \
  --duration-s 120 \
  --max-speed-deg-s 30 \
  --max-gripper-speed-s 60 \
  --wrist-max-speed-deg-s 20 \
  --wrist-gain-per-s 3 \
  --wrist-max-travel-deg 60
```

运行前人工摆齐两臂；输入 `FOLLOW` 后才给白臂上扭矩。现场必须有人清空运动范围并能够立即断开 12V。
