# 实验记录 06 · RGB-D 桌面物体定位与黑臂抓取准备

- **日期**：2026-08-03
- **平台**：Mac（Apple Silicon）+ Orbbec Gemini 335 + XLeRobot 黑色 SO-101 臂
- **任务**：用固定朝下的头部 RGB-D 相机定位桌面浅蓝色面霜罐，并确认黑臂可在当前桌边停靠位完成抓取。
- **状态**：✅ 感知已验证；✅ 人工键盘遥操作抓取成功；✅ 受监督固定轨迹已完成真实拿起与放回；⏳ 尚未实现相机坐标驱动的自动抓取。

## 1. RGB-D 感知验证

在 `simtoreal` 分支的 `cameratest/` 中，以 Gemini 335 官方 SDK 的 RGB 与对齐深度流进行颜色分割和鲁棒深度估计。浅蓝色矮圆柱面霜罐在灰色窗帘等相似背景存在时，加入桌面 ROI 后稳定定位；纯蓝色目标不是本次验证的必要条件。

本次居中放置面霜罐的稳定观测示例：

| 输出 | 数值 | 含义 |
|---|---:|---|
| center x (right) | +2.1 mm | 相对相机光轴向右 |
| center y (down) | +15.0 mm | 相对相机光轴向下 |
| center z (forward) | +477.9 mm | 相对相机光轴前方 |
| range | 477.2 mm | 相机到目标表面的直线距离 |
| confidence | 0.93 | 当前颜色/深度观测置信度 |
| depth MAD | 6.0 mm | 深度块内部离散度，越小越稳定 |

`x/y/z` 都是**相机光学坐标系**：相机向下俯视时，`y down` 不等于世界坐标的高度。后续必须求得相机到黑臂基座的刚体变换 `T_base_camera`，才能把该点用于机械臂控制。

## 2. 黑臂可达性与抓取验证

- 移动底盘置物架已贴住桌边；目标位于黑臂可达范围内。
- 使用已验证的 [`tools/arm_keyboard.py`](../tools/arm_keyboard.py) 控制黑臂（`python tools/arm_keyboard.py black`，复用 `black_arm.json` 标定）。
- 已人工完成“靠近 → 对准 → 合爪 → 抬起”一次，确认当前黑臂、夹爪和桌边停靠关系可完成该物体的抓取。

这不是自动抓取结果：动作是键盘遥操作完成的，且该脚本启动后会归零，因此每次运行前须清空机械臂周围区域。

### 已录制固定轨迹

2026-08-05 已通过黑臂键盘控制记录四个控制器关键帧：`pregrasp_open` → `descend_open` → `close_gripper` → `lift`。它们已写入 [`tools/black_arm_facecream_replay.py`](../tools/black_arm_facecream_replay.py)，该脚本逐阶段请求 `MOVE` 确认、低速插值并可选择受监督放回；只适用于本记录中的固定桌边场景。

**真实硬件结果（2026-08-05）**：该回放已在固定场景中完成一次完整的“回零 → 预抓取 → 下探 → 合爪 → 抬起 → 放回 → 退回”流程。每个阶段均由现场人工输入 `MOVE` 放行；没有发生碰撞。该结果证明录制的控制器关键帧可被同一控制器低速复用，但不等同于任意物体位置的自主抓取。

## 3. 已识别的边界

- 小物体的颜色分割容易受背景、阴影和物体尺寸影响；当前以固定面霜罐和固定桌面 ROI 做窄任务验证。
- YOLO/通用类别检测可作为后续替换方案，但本次不需要先解决开放类别小物体检测。
- 相机位置、俯仰角和底盘停靠位必须固定；一旦移动头部云台或底盘，外参需要重新检查。

## 4. 下一步：从“能看见、能手抓”到自动抓取

1. 固定 Gemini 云台、黑臂基座、桌边停靠位和面霜初始位置。
2. 标定 `T_base_camera`：采集若干已知黑臂末端位置及相机中对应点，拟合相机坐标到黑臂基座坐标的变换。
3. 定义安全抓取状态机：预抓取点 → 垂直下降 → 合爪 → 抬升；每段保留可中止和人工监督。
4. 接入黑臂的真实逆运动学和关节限位，再用同一物体重复验证。
5. 在确定性闭环稳定后，再采集遥操作示范数据并训练 ACT / VLA 基线。
