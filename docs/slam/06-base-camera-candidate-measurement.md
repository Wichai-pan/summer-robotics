## 现场定义

操作者通过整机俯视图和 `+Y` 侧视图确认 `base_link` 使用 ROS 前、左、上坐标约定：

- 原点：底盘架内切圆的地面几何中心；
- `+X`：朝桌面和白纸；
- `+Y`：朝黑色机械臂；
- `+Z`：从地面向上。

两张照片用于确认方向和安装关系，不用于从透视图估算尺寸。

## 测量与计算

在 SLAM 正前方姿态下，现场测得 Gemini 底部安装螺丝中心相对 `base_link`：

```yaml
base_to_bottom_screw_m: [-0.065, 0.000, 1.170]
```

Orbbec 官方 Gemini 335 URDF 给出：

```yaml
camera_link_to_bottom_screw_m: [-0.01587, -0.02500, -0.01250]
```

相机按正前方、水平和 roll=`0 deg` 记录，因此采用单位旋转。计算结果为：

```yaml
parent_frame: base_link
child_frame: camera_link
translation_m: [-0.04913, 0.02500, 1.18250]
rotation_xyzw: [0.0, 0.0, 0.0, 1.0]
gimbal_reference_raw: {"7": 4068, "8": 1694}
status: candidate
```

## 适用边界

该结果是用于低速监督移动 VO 的工程候选值，不是精密外参标定。正前方和水平仍需在
条件允许时用角度基准复核；任何非零旋转都会影响官方螺丝偏移换算后的平移。

本轮没有启动 Gemini、容器、底盘或机械臂，没有修改 Jetson、固件或标定文件，也没有
进行移动 VO 或建图。live 入口继续保持封锁，直到单一硬件锁监督会话完成并通过评审。
