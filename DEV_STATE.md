# Development State

Updated 2026-08-25 (confirmed evidence only): the project has separate but partially verified fixed-scene ACT grasping, Gemini RGB-D mapping/localization, and supervised base-navigation components. ACT v2 has physically grasped, short-transferred and placed the fixed face-cream object, but its grasp success is not repeatable because the checkpoint has no explicit contact/success observation. The current mapping candidate remains `/data/slam/mapping/20260814T140025Z/rtabmap.db` with downward Gemini reference ID7 raw=4066/ID8 raw=1924; it is an old-room map and cannot yet support arbitrary-start global navigation. On branch `codex/fix-base-stop-idle-jitter`, Nav2 plans from a fresh map-frame pose while the executor uses measured wheel velocities from IDs 7/8/9 as its 5 Hz local pose and uses RGB-D for liveness plus bounded translation correction. Read-only bus-cadence and verified active-brake/torque-off checks passed. A supervised 1.284 m Nav2 plan to `(1.200, -0.461, 0 degrees)` completed in `/data/slam/nav2-supervised-execute/20260824T141037Z`: the controller reported arrival 6.29 cm from goal with 7.23 degrees yaw error after 56.488 s, all wheels verified zero and torque-free, and the operator measured about 1.30 m physical travel. This establishes a supervised long-leg baseline near the known map start, not robust map-based navigation. A later 0.518 m table-side route to `(-0.250, -0.411, -90 degrees)` failed safely at its 35 s cap after the rotation/translation estimate diverged: wheel pose and RGB-D yaw differed by roughly 45–50 degrees early in the turn, and nominal pure-turn feedback became uneven (for example IDs 7/8/9 = -600/-150/+200 raw). The controller then reoriented repeatedly and the operator reported contact with the desk. Commit `379f2bb` extends the existing 5 cm rotate-only drift guard to wheel control. On 2026-08-25, the new `tools/base_turn_diagnostic.py` completed paired floor-reference tests: feedback 90°+30° (about 120° total) was physically about 90° for both left and right turns, with verified zero/torque-free wheel shutdown. `tools/nav2_supervised_base_execute.py` now therefore applies a bounded default `--wheel-yaw-scale 0.75` only to wheel-feedback yaw integration; it is a provisional floor calibration that needs a supervised navigation re-test, not a solution for slip or old-map localization. Next: in clear open space re-test a short planned route with this scale, then re-test a table dock only if its turn and stop behavior are physically correct. Only after a repeatable dock should the system switch Gemini to the ACT grasp reference and run a gated navigation-to-grasp MVP. Core files are `tools/nav2_supervised_base_execute.py`, `tools/base_turn_diagnostic.py`, `tools/base_stop_diagnostic.py`, `tools/base_shutdown_sequence_diagnostic.py`, the `scripts/jetson_slam_*` wrappers, and `docs/slam/14-supervised-nav2-long-leg-and-rotation-divergence-20260824.md`.
